# Registro Ore 3.11.0

## Novità

- Nove **Categorie** gestionali con regole integrate; non è più presente il campo separato «Regola operativa».
- Sezione **Rendicontazione** organizzata per nove categorie, inclusa «Commissioni».
- **Gestione → Guida alle categorie**: esempi, esclusioni e comportamento durante la sospensione delle lezioni.
- Missioni scientifiche e istituzionali con periodo, ruolo, conferenza, paper, DOI, progetto e documenti, associabili alle singole registrazioni senza duplicare le ore.
- Migrazione conservativa con backup e conservazione delle vecchie denominazioni per revisione delle corrispondenze incerte.

## Prima dell'aggiornamento

Chiudere Registro Ore e verificare il **database effettivamente utilizzato**. Conservare un backup esterno. Dopo l'aggiornamento controllare la classificazione delle attività storiche, soprattutto quelle che usavano categorie personalizzate. Non sostituire il database personale con quello vergine fornito negli installer.

## Compatibilità e limitazioni

Java 17+, macOS, Windows 10/11 x64 e Linux Mint x64. I pacchetti non sono firmati digitalmente. Le categorie sono una convenzione dell'app, non una dichiarazione di conformità automatica a U-Web, norme di Ateneo o singoli bandi. Prima di una distribuzione estesa eseguire un collaudo pratico su ciascun sistema operativo.
