# Registro Ore v3.10.1

**Applicazione desktop Java + SQLite per rendicontazione ore didattiche e progetti.**

## Distribuzioni

- macOS: pacchetto per prima installazione e aggiornamento con doppio clic.
- Windows 10/11 x64: eseguibile portabile in ZIP.
- Linux Mint x64: installer `.deb` e versione portabile.

## Principali funzioni

- Registro multiannuale con 1.500 ore/anno, sospensioni didattiche e blocchi mensili.
- Riepiloghi, ricerca per periodo, esportazioni CSV/XLSX.
- Progetti, collaboratori, storico ruoli e costi per data.
- Allegati, backup giornalieri e storico modifiche.
- Controllo database all'avvio e percorso mostrato nell'interfaccia.
- **Correzione 3.10.1:** icone della barra laterale disegnate con Java2D anziché caratteri Unicode non affidabili.

**Avviso:** gli eseguibili non sono firmati/notarizzati e non sono stati verificati su tutti i sistemi reali. Verificare integrità e provenienza prima dell'installazione.

Per le istruzioni complete consultare `docs/MANUALE_UTENTE.md`.
