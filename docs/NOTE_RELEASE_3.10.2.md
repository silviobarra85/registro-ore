# Registro Ore v3.10.2 — Correzione posizione del Registro

### Correzione

Dopo aver modificato un'attività o il numero delle ore, **il Registro mensile non torna più all'inizio del mese**. Il giorno interessato rimane nel punto della schermata in cui si trovava prima del salvataggio. Lo stesso comportamento si applica all'eliminazione di una registrazione.

### Compatibilità

- Java 17+.
- Database SQLite precedente compatibile: **nessuna migrazione e nessuna modifica delle ore**.
- Aggiornamento Mac con doppio clic, Windows 10/11 64 bit e Linux Mint 64 bit.
- I database personali non sono inclusi negli installer. Creare comunque un backup prima di aggiornare.

### Distribuzione

Scaricare l'installer adatto al sistema operativo dalla sezione Assets di questa Release.
Gli eseguibili non sono firmati né collaudati su tutti i sistemi reali; controllare origine e SHA-256 prima dell'installazione.
