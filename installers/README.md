# Installer — Registro Ore 3.10.1

Questa cartella contiene **i cinque pacchetti binari della versione 3.10.1**:

| Sistema | File | Uso |
|---|---|---|
| macOS | `macos/RegistroOre_3_10_1_MAC_VERGINE.zip` | Nuova installazione, senza dati personali |
| macOS | `macos/RegistroOre_3_10_1_MAC_AGGIORNAMENTO.zip` | Aggiornamento di un'installazione esistente |
| Windows | `windows/RegistroOre_3_10_1_Windows_x64.zip` | Windows 10/11 x64, avvio `.exe` |
| Linux Mint | `linux/RegistroOre_3_10_1_LinuxMint_amd64.deb` | Installazione `.deb` |
| Linux Mint | `linux/RegistroOre_3_10_1_LinuxMint_Portabile.zip` | Esecuzione portabile, Java 17+ |

**Verifica file:** confrontare il checksum SHA-256 con `SHA256SUMS.txt` prima di diffondere i pacchetti. Gli installer e i JAR sono **non firmati digitalmente**.

**Non inserire qui** copie personali di `registro_ore_2026.sqlite`, timesheet, log o allegati.

Per gli aggiornamenti futuri: pubblicare i pacchetti su **GitHub Releases** e mantenere la cartella `installers/` ordinata, con i soli file della versione corrente.
